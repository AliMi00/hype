# Step 2 — Pitch video ideas

The goal: 3–5 ideas that are **different from each other**, **specific to this
subject**, and **makeable with the material we have**. The user should want to
make at least one of them immediately.

## How to generate

1. Start from the brief: audience, pain/desire, promise, proof, goal.
2. For each angle below that fits, write a one-line concept. Aim for 10–15
   candidates internally. Don't show these.
3. Score each (below), keep the best, and make sure the final set spans
   different formats and at least two different emotions (e.g. funny + useful).
4. Write the hook for each — the literal words/visual of the first 2 seconds.
   If you can't write a strong hook, drop the idea.

## Angles

| Angle | The idea in one line | Great for |
|---|---|---|
| Pain → fix | Show the annoying "before", then the product making it vanish | Tools, services, apps |
| Transformation | Before/after, split screen or a wipe | Visual products, design, fitness, food |
| Speed demo | "From X to Y in 10 seconds" — the product doing its job, fast | Software, gadgets |
| POV | "POV: you just found …" — viewer is the main character | Consumer, lifestyle, B2C apps |
| Listicle | "3 things you didn't know <product> can do" | Feature-rich products |
| Myth vs fact | Bust a common misconception in the audience's world | Education, health, finance, B2B |
| Contrarian | "Stop doing X." Then the better way | Thought leadership, B2B |
| Comparison | Old way vs new way (never trash a named competitor) | Switching products |
| Numbers | One striking real stat, animated | Products with real traction/proof |
| Behind the scenes | How it's made, the team, the build | Makers, food, craft, indie dev |
| Story | Tiny narrative: character, problem, turn, resolution | Brands, causes, events |
| Challenge / game | "Can you spot …", "Guess the …", quiz with reveal | Engagement, community |
| Countdown / launch | "Launching in 3… 2… 1" with teasers | Launches, events, drops |
| Offer | The deal, the deadline, the urgency — clean and honest | Sales, promos, events |
| FAQ answer | Answer the #1 question people ask | Any; great for trust |
| Satisfying | Smooth, loopable, ASMR-ish product motion | Visual/physical products, UI polish |
| Meme format | A familiar format ("Nobody: / Me:", "Expectation vs reality") | Casual brands, dev tools, Gen Z |
| Testimonial-style | A real user quote, animated (only if real) | Social proof |
| Tutorial | "How to <outcome> in 3 steps" using the product | Tools, recipes, skills |
| Announcement | New feature/version, clear and punchy | Existing products |

## Hook formulas

Use the audience's language and the product's specifics — these are shapes:

- "Stop <common mistake>." / "You're doing <task> wrong."
- "I <did impressive thing> in <tiny time> with <product>."
- "POV: <relatable moment>."
- "This <thing> shouldn't be free." / "This feels illegal to know."
- "<Number> <things> <audience> need to know about <topic>."
- "Nobody talks about <pain>."
- "Watch this <before> become <after>."
- "If you <identity/situation>, you need to see this."
- A bold visual first frame with no words: the result, mid-motion.

Never: a logo intro, "Hi guys", "Introducing…" as the first words, a fade from
black, or text that needs context to make sense.

## Match goal to format

| Goal | Strong formats |
|---|---|
| Launch | Countdown, Speed demo, Announcement, Pain → fix |
| Signups / downloads | Pain → fix, POV, Tutorial, Speed demo |
| Sales / offer | Offer, Transformation, Testimonial-style (real), Numbers |
| Event | Countdown, Story, Behind the scenes, Offer (tickets) |
| Awareness | Story, Contrarian, Myth vs fact, Meme format |
| Feature | Announcement, Listicle, Speed demo |
| Hiring | Behind the scenes, Story, POV ("POV: your first week at…") |
| Community | Challenge / game, Meme format, FAQ answer |

## Score each candidate (1–5)

- **Hook** — would *this audience* stop scrolling for the first two seconds?
- **Clarity** — does a stranger get what it is and why they'd care?
- **Fit** — does it serve the goal and suit the platform?
- **Proof** — does it show the real product/result rather than claim it?
- **Makeable** — can we build it well with the material available, honestly?
- **Shareable** — would someone send it to a friend or save it?

Drop anything with Makeable ≤ 2 or that would need invented facts. Recommend
the highest total; break ties with Hook.

## Writing `ideas.md`

```markdown
# Video ideas — <name>

## 1. <Catchy working title>  ⭐ recommended
**Format:** Pain → fix · **Platform:** TikTok / Reels / Shorts · **Aspect:** 9:16 · **Length:** 15s · **Tone:** bold
**Hook (0–2s):** "<exact on-screen words>" over <visual>.
**Beats:** 1) … 2) … 3) … → CTA "<exact CTA>"
**Why it works:** one or two sentences tied to the audience and goal.
**Needs:** what material it uses (and anything missing from the user).

## 2. …
```

In chat, show the same thing compactly (skip "Needs" unless something is
missing), then ask: *"Which one should I make? Pick a number, a few, or mix
them — and tell me if you want other sizes (9:16, 16:9, 1:1, 4:5…)."*

If the user asked for more ideas, generate new ones — don't repeat.
